# Edge AI Benchmark Suite

Edge AI Benchmark Suite — инструмент для оценки производительности моделей компьютерного зрения на разных аппаратных платформах. Проект собирает системную информацию, запускает бенчмарк моделей и сохраняет результаты в CSV/JSON-отчёты.

## Возможности

- сбор сведений о CPU, GPU, RAM, NPU, температуре и операционной системе;
- запуск набора бенчмарков для выбранных моделей;
- генерация отчётов в форматах CSV и JSON;
- простая настройка через YAML-конфиг.

## Требования

- Python 3.10+
- зависимости из файла requirements.txt

Установка:

```bash
pip install -r requirements.txt
```

## Запуск

Базовый запуск:

```bash
python main.py --config core\configs\example.yaml run
```

## Конфигурация

Конфиг задаётся через YAML. Основные разделы:

- `system_info` — включить сбор данных о системе;
- `benchmark` — параметры запуска бенчмарка;
- `output` — форматы отчётов и каталог для сохранения.

Пример конфигурации находится в [core/configs/example.yaml](core/configs/example.yaml).

## Пайплайн

1. Чтение конфигурации.
2. Сбор сведений о железе и ОС.
3. Запуск benchmark-пайплайна для выбранных моделей.
4. Сохранение результатов в отчёты в папке results/.

## Структура проекта

- `application/` — CLI, запуск benchmark и формирование отчётов;
- `core/` — модели данных, конфиги и перечисления;
- `infrastructure/` — сбор hardware-метрик, чтение конфигов и reporting;
- `results/` — сгенерированные отчёты;
- `tests/` — pytest.
